# Skill: Growth Advisory (Principal Growth)

> Persona: [`personas/growth-marketing.md`](../personas/growth-marketing.md) · Council: [`planner-council.md`](../workflows/planner-council.md)

---

## 1. Gate de qualidade (rejeitar se falhar)

| # | Critério |
|---|----------|
| G1 | ICP + job + alternativa atual (mesmo que hipótese marcada) |
| G2 | Promessa única **falsificável** (o usuário pode discordar) |
| G3 | Funil com **1 métrica âncora** por etapa relevante ao escopo |
| G4 | Se ASO/store no escopo: keywords com **por quê** (intenção/fit) |
| G5 | Separação explícita: **in-scope agora** vs **backlog** |
| G6 | Se N/A aquisição: modo interno completo (não 3 linhas) |

**Falha automática:** “3 títulos + TikTok + Instagram + lead magnet” sem ICP/métrica/racional.

---

## 2. Processo

1. Ler draft + parecer UX (não contradizer IA interna).
2. Classificar superfície: **produto consumidor** / **landing** / **store** / **interno**.
3. Definir ICP e mensagem.
4. Se store/landing no escopo → ASO + criativo; senão → messaging + ativação.
5. Propor só o que cabe no pedido; resto → backlog.
6. Entregar aceite Growth testável quando houver arquivos (listing, About, pricing CTA).

- Documentar a fronteira; não mandar laranja no dashboard sem pedido.
